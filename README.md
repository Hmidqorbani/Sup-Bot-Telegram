# Sup‑Bot

**Sup‑Bot**
یک ربات تلگرامی ساده برای برقراری ارتباط بین کاربران و مدیر (ادمین) است. این ربات امکان دریافت پیام از کاربران، ارسال پیام توسط ادمین، نمایش پیام خوش‌آمدگویی، و پیاده‌سازی قابلیت **جوین اجباری** برای کانال‌های خاص را فراهم می‌کند.

## معرفی

Sup‑Bot با استفاده از کتابخانهٔ **python‑telegram‑bot** نوشته شده و برای موارد زیر مناسب است:

1. دریافت پیام‌های کاربران و ارسال فوری به ادمین.
2. ارسال پاسخ از طرف ادمین به کاربر با حفظ ردیابی پیام‌ها.
3. نمایش پیام خوش‌آمدگویی قابل تنظیم.
4. اعمال **جوین اجباری** برای عضویت کاربران در یک یا چند کانال قبل از استفاده از ربات.
5. داشبورد سادهٔ آمار کاربران و پیام‌های در انتظار پاسخ.

به‌صورت پیش‌فرض تمام متن‌ها و پیام‌ها به زبان فارسی هستند؛ می‌توانید به راحتی آن‌ها را برای زبان‌های دیگر تغییر دهید.

## امکانات

| ویژگی | توضیح |
|-------|-------|
| **پشتیبانی از پیام‌های کاربر** | پیام‌های دریافت‑شده از کاربران به صورت خودکار به ادمین فوروارد می‌شود. |
| **پاسخ ادمین** | ادمین می‌تواند با پاسخ دادن به پیام فوروارد شده، همان پیام را برای کاربر ارسال کند. |
| **پیام خوش‌آمدگویی** | متن خوش‌آمدگویی از فایل `welcome.txt` خوانده می‌شود؛ می‌توانید با منوی ادمین آن را تغییر دهید. |
| **جوین اجباری** | با فعال‌سازی این گزینه، کاربران باید پیش از استفاده از ربات در کانال/کانال‌های مشخص شده عضو شوند. |
| **آمار ربات** | تعداد کل کاربران و پیام‌های در انتظار پاسخ در منوی ادمین نمایش داده می‌شود. |
| **پیام همگانی** | ادمین می‌تواند یک پیام متنی به همهٔ کاربران ربات بفرستد. |
| **ذخیره‌سازی داده‌ها** | کاربران در فایل `users.json`، تنظیمات جوین در `force_join.json` ذخیره می‌شوند. |

## نحوهٔ راه‌اندازی

### پیش‌نیازها

1. **Python 3.9+**
2. **pip** (مدیریت بسته‌های پایتون)
3. توکن ربات تلگرام (دریافت از [BotFather](https://t.me/BotFather))
4. شناسهٔ عددی ادمین (آی‌دی تلگرام خودتان)

### مراحل نصب

```bash
# 1️⃣ کلون کردن مخزن (اگر هنوز این کار را نکرده‌اید)
git clone https://github.com/yourusername/Sup-Bot.git
cd Sup-Bot

# 2️⃣ ایجاد محیط مجازی (اختیاری ولی توصیه می‌شود)
python -m venv .venv
source .venv/bin/activate   # در ویندوز: .venv\Scripts\activate

# 3️⃣ نصب وابستگی‌ها
pip install -r requirements.txt
```

### تنظیم متغیرهای محیطی

به‌جای قرار دادن مقادیر حساس (توکن ربات و آی‌دی ادمین) در کد، می‌توانید از متغیرهای محیطی استفاده کنید. دو گزینه در کد وجود دارد:

- **روش مستقیم (در فایل `app.py`):**
  ```python
  BOT_TOKEN = "YOUR_BOT_TOKEN"
  ADMIN_ID = YOUR_ADMIN_ID
  ```
- **روش توصیه‌شده (متغیرهای محیطی):**
  ```python
  BOT_TOKEN = os.getenv("BOT_TOKEN")
  ADMIN_ID = int(os.getenv("ADMIN_ID"))
  ```
  سپس در خط فرمان مقداردهی کنید:

```bash
export BOT_TOKEN=YOUR_BOT_TOKEN
export ADMIN_ID=YOUR_ADMIN_ID
```

### اجرا

```bash
python app.py
```

پس از اجرای برنامه، ربات در حالت «polling» به تلگرام متصل می‌شود و پیام‌های `/start` و `/admin` را پردازش می‌کند.

## پیکربندی

| فایل | توضیح |
|------|-------|
| `users.json` | لیست شناسه‌های کاربران (آی‌دی) که ربات آن‌ها را می‌شناسد. به‌صورت خودکار به‌روز می‌شود. |
| `welcome.txt` | متن خوش‌آمدگویی که هنگام `/start` برای کاربر ارسال می‌شود. اگر وجود نداشته باشد، پیام پیش‌فرض استفاده می‌شود. |
| `force_join.json` | تنظیمات مربوط به جوین اجباری. ساختار پیش‌فرض:
```json
{ "enabled": false, "channels": [] }
```
| `app.py` | منبع اصلی ربات. حاوی تنظیمات توکن، آی‌دی ادمین، و توابع اصلی. |

### تغییر پیام خوش‌آمدگویی

1. به ربات به‌عنوان ادمین پیام `/admin` بدهید.
2. از منوی `📝 تغییر خوش‌آمدگویی` استفاده کنید و متن جدید را ارسال کنید.

### تنظیم جوین اجباری

1. در منوی ادمین بر روی `🔒 جوین اجباری` کلیک کنید.
2. با `➕ افزودن کانال`، عنوان و لینک تلگرامی (مثلاً `https://t.me/mychannel`) کانال را وارد کنید.
3. با `وضعیت: روشن ✅` یا `خاموش ❌` قابلیت جوین را فعال/غیرفعال کنید.

## دستورات ربات

| دستور | توضیح |
|-------|-------|
| `/start` | نمایش پیام خوش‌آمدگویی و بررسی عضویت در کانال‌های اجباری. |
| `/admin` | نمایش منوی مدیریت (فقط برای ادمین). |
| `/cancel` | لغو عملیات در حال انجام (مثل افزودن کانال یا ارسال پیام همگانی). |

در داخل منوی ادمین می‌توانید دستورات زیر را از طریق کلیدهای اینلاین انتخاب کنید:

- 📊 **آمار** – تعداد کاربران و پیام‌های انتظاری.
- 📢 **پیام همگانی** – ارسال متن به تمام کاربران.
- 📝 **تغییر خوش‌آمدگویی** – تنظیم متن خوش‌آمد.
- 👀 **مشاهده خوش‌آمدگویی** – نمایش متن فعلی.
- 🔒 **جوین اجباری** – مدیریت کانال‌های مورد نیاز برای عضویت.
